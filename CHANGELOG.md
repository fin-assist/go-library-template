# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии и выпуск — [docs/releasing.md](docs/releasing.md). Каждый PR библиотеки, включая документацию, тесты и CI, добавляет строку в «Unreleased»; исключение — полностью ботские PR Renovate только с зависимостями, их сводку по `go.mod` добавляет PR выпуска. При выпуске раздел получает номер версии и дату.

## [Unreleased]

### Изменено

- FIN-310: `internal/pgtest` больше не копирует go-migrate: оставлен только выбор тестового PostgreSQL (`TEST_DATABASE_URL`/testcontainers, skip локально, ошибка в CI), создание БД, правила файлов и обход up → down → up делегированы `github.com/fin-assist/go-migrate` v0.1.1 (`migratetest`, `migrate.Validate`). go-migrate импортируется только тестами, но как require модуля входит в граф модулей и повышает минимальную версию go-migrate у сервисов, импортирующих библиотеку (сервисы уже на v0.1.1); прямая `golang-migrate` ушла в indirect. Исключение `internal/pgtest` из покрытия не изменилось; runtime и экспортируемый API не менялись.
- FIN-294: `forbidigo` запрещает все найденные пути к глобальному состоянию: стандартные логгеры (`fmt.Print*`, `print`, `slog`/`log` пакета, `grpclog`), глобальный реестр метрик (`prometheus.DefaultRegisterer`/`DefaultGatherer`, `promauto.New*`, `promhttp.Handler`), `http.DefaultClient` и функции пакета `http`, глобальные провайдеры `otel` (включая `otel.Tracer`/`Meter`/`Handle` и `otel/log/global`), `os/signal` и окружение (`os`, `syscall`, `golang.org/x/sys`, включая Win32). `depguard` запрещает даже пустой импорт `expvar`, `net/http/pprof`, `golang.org/x/net/trace`, `grpclog/glogger`, `glog`, `klog`, `automaxprocs` и `automemlimit`. `scripts/test_lint_policy.py` прогоняет закреплённый golangci-lint на герметичном пробном модуле для linux и windows, включая цепочки и импорт под псевдонимом. По решению владельца запрещены также функции пакета `flag` и `flag.CommandLine`, `os.Stdout`/`Stderr`/`Stdin`, `os.TempDir`/`CreateTemp`/`MkdirTemp`, `runtime/debug.Set*`, `runtime.GOMAXPROCS`/`SetDefaultGOMAXPROCS` и смена рабочего каталога (`os.Chdir`, `(*os.File).Chdir`, `syscall`/`x/sys`); `flag.NewFlagSet` с методами переданного `*flag.FlagSet` разрешён. Runtime и экспортируемый API не менялись.
- FIN-247: только исходный пустой go-library-template сообщает N/A для coverage после обязательного успешного выполнения всех трёх наборов. При появлении production statements автоматически действуют прежние total80; новые библиотеки не наследуют исключение. Проверки suites, required go, защиты и Controller Renovate сохранены; runtime и публичный API не менялись.
- FIN-307: правила `docs/releasing.md` и вступление CHANGELOG требуют строку в `[Unreleased]` от каждого PR, включая документацию, тесты и CI; заголовок PR выпуска — с ключом FIN; полностью ботские PR Renovate только с зависимостями строку не добавляют, их сводку по `git diff <тег> -- go.mod` вносит PR выпуска; README перечисляет `local-prefixes`, `doc.go`, ожидаемое имя и судьбу `migration_api_test.go`, очистку `[Unreleased]` при создании библиотеки. Runtime и экспортируемый API не менялись.
- FIN-243: независимые statements-профили unit/integration/API и обязательные пороги80 с готовым go-test-coverage v2.20.1; guards пустых/пропущенных наборов, исполнение Example/Fuzz и проверки публичного Go API. Только тестовый пакет internal/pgtest исключён из одинакового знаменателя всех трёх уровней; его тесты продолжают выполняться. Документирован эффект постоянно красного go на Renovate retry/close/quarantine и необходимость отдельного решения об операционной паузе. Runtime и экспортируемый API не менялись.
- FIN-301: CI не оставляет токен checkout в jobs `lint`, `api` и `migrations`, а имя базовой ветки передаётся в скрипт `migrations` через окружение; тест `scripts/test_workflow_hardening.py` разбирает workflow через PyYAML и запрещает любое `${{` в `run` и checkout без `with.persist-credentials: false`. Runtime и экспортируемый API не менялись.
